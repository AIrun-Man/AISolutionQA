# Existing Automation Intelligence

## Inputs

- Test Inventory and Automation Repository Model
- Framework and Repository Standards Models
- Explicit script-to-test, requirement, API, component, business-logic, utility, and suite links

## Instructions

Identify reusable active scripts, page objects, locators, utilities, request builders, API clients, and authentication helpers. Preserve source repository, path, revision, test/Xray links, and known limitations. Reuse only explicit traceable matches; classify partial matches as extension candidates. Never modify, execute, or publish an existing asset as a side effect of analysis.

## Output

Return an Automation Reuse Inventory with exact reusable and partial asset references and unresolved mappings.
